# Changelog

All notable changes to Shijian will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project intends to follow Semantic Versioning after the first public release.

## [Unreleased]

### Added

- Open-source project documentation and contribution guidelines.
- GitHub Issue and Pull Request templates.
- Windows CI and tag-based release automation.

### Changed

- Project metadata is prepared for a public MIT-licensed release.
- First-run draft storage uses the user's system Documents directory instead of a machine-specific path.

## [0.1.0] - 2026-08-18

Initial public preview.

### Added

- Local UTF-8 TXT draft storage.
- Draft creation, editing, renaming and recycle-bin deletion.
- Auto-save and external file-change detection.
- System tray support.
- Global shortcuts for show/hide and new draft.
- Always-on-top and startup settings.
- Light, dark and transparent display modes.
- Fixed-canvas native Windows Region architecture for collapsed, directory and preview states.
- Multi-DPI and dual-monitor window handling.
